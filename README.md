# ペグブロック

十字盤のペグソリティアに 2048 の合体ルールを組み合わせた、1人用の得点パズル。上から見た盤で、数字の書かれたブロックをスワイプして遊びます。ビルド不要の静的サイトです。

## ルール

- 7×7 のうち 33 マスを使う英国式の十字盤。開始時は中央だけが空きで、残り 32 マスに「2」のブロックが並ぶ。
- ブロックをスワイプすると、その方向に並んだ**同じ数字**のブロックを**何個でも**まとめて飛び越えて、その先の空きマスへ着地する。
  - 動かすブロックの隣から、同じ数字のブロックが 1 個以上連続して並び、その次が空きマスのときに動ける。何個並んでいてもよい。
  - 途中に違う数字のブロックがあったり、空きマスがなく盤の端まで詰まっていたりするときは、その向きには動けない。
  - タップで選んでから、移動先（目印の丸）をタップしても動かせる。斜めには動けない。
- 飛び越えたブロックはすべて消え、動かしたブロックは着地したマスで数字が **2 倍**になる（何個飛び越えても 2 倍は 1 回）。できた数字がそのまま得点。
- 四方の 2×3（腕）のどれかでブロックが 1 個もなくなったら、その腕の 6 マスにブロックがまるごと補充される。中央の 3×3 は補充されない。
- **補充される数字は、そのとき盤上にあるいちばん小さい数字**。2 が 1 個もなければ 4、4 もなければ 8…と上がっていく。同時に複数の腕が空いたら、すべて同じ数字で補充される。補充は合体と得点の処理のあとに起きる。
- どのブロックにも合法な手がなくなったら終了。得点・手数・補充回数・最大の数字を表示し、ベストは得点で記録する。
- 「戻す」とヒントはない。

## 効果音の設計

気持ちよく聞こえるように、音響心理学の知見をもとに次のように作っています（`public/sound.js`）。

- **すぐ鳴らす**：音と動きのずれは数十msでも気づかれるため、操作と同時に鳴らす。
- **協和する音だけ**：倍音が整数倍に並ぶ音（サイン波＋弱い倍音）と、どの音を重ねても濁らないメジャー・ペンタトニック音階を使う。
- **耳に刺さる帯域を削る**：不快さに最も効く 2〜4kHz を避けるため、基音を低めにしてローパスをかける。うなりの原因になるデチューンもしない。
- **達成感を音程で**：大きい数字ができるほど、連続で合体するほど音が上がる。上がりすぎると耳障りなので上限を設け、2.5秒手が止まったらリセット。
- **聞き飽きさせない**：合体音は毎回わずかに音程を揺らす。補充やベスト更新の音は毎回同じにして「ごほうびの合図」として覚えられるようにする。
- **失敗は責めない**：動かせないときは、低く柔らかい下降2音を短く鳴らすだけ。終了音も主音に落ち着いて終わる。
- 右上のボタンで音のオン・オフを切り替えられる（設定は保存）。

## ファイル構成

```
public/          公開するファイル一式（Cloudflare Pages の出力ディレクトリ）
  index.html
  style.css
  logic.js       ルール本体（描画から独立。Node からも読み込める）
  game.js        2D盤の描画とスワイプ操作
  sound.js       効果音（Web Audio で合成）
  favicon.svg
  _headers       Cloudflare Pages 用のレスポンスヘッダー
wrangler.toml    Cloudflare Pages の設定（出力ディレクトリ = public）
```

## ローカルで動かす

```sh
npx http-server public -p 8787
# → http://localhost:8787/
```

## Cloudflare Pages で公開する

Workers & Pages → Create → Pages → 「Connect to Git」でこのリポジトリを選び、Framework preset は `None`、Build command は空欄、Build output directory は `public` にする。
コマンドで出す場合は `npx wrangler pages deploy public --project-name peg-block`。
