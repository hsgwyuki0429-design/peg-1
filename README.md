# ペグブロック

十字盤のペグソリティアに「補充」を足した、1人用のパズル。数字も合体もなく、ペグを飛び越えて取っていくだけ。
上から見たカラフルな2D盤で、ペグをスワイプして遊びます。ビルド不要の静的サイトです。

## ルール

- 7×7 のうち 33 マスを使う英国式の十字盤。開始時は中央だけが空きで、残り 32 マスにペグが並ぶ。
- ペグをスワイプすると、その方向に隣り合うペグを1つ飛び越えて、その先の空きマスへ着地する（タップで選んでから移動先をタップしても動かせる）。斜めには動けない。
- 飛び越えたペグは盤から消え、1 点。
- 四方の 2×3（腕）のどれかでペグが 1 個もなくなったら、その腕の 6 マスにペグがまるごと補充される（ただ補充されるだけで、得点やボーナスはない）。中央の 3×3 は補充されない。同時に複数の腕が空いたら、すべて補充される。
- ペグの色は出身の区画で決まり、動かしても変わらない。
- どのペグにも合法な手がなくなったら終了。得点・残りペグ・補充回数・戻した回数を表示し、ベストは得点で記録する。
- 「戻す」は回数無制限。ヒント機能はない。

## 効果音の設計

気持ちよく聞こえるように、音響心理学の知見をもとに次のように作っています（`public/sound.js`）。

- **すぐ鳴らす**：音と動きのずれは数十msでも気づかれるため、操作と同時に鳴らす。
- **協和する音だけ**：倍音が整数倍に並ぶ音（サイン波＋弱い倍音）と、どの音を重ねても濁らないメジャー・ペンタトニック音階を使う。
- **耳に刺さる帯域を削る**：不快さに最も効く 2〜4kHz を避けるため、基音を低めにしてローパスをかける。うなりの原因になるデチューンもしない。
- **達成感を音程で**：連続でジャンプするほど音が上がる。上がりすぎると耳障りなので上限を設け、2.5秒手が止まったらリセット。
- **聞き飽きさせない**：ジャンプ音は毎回わずかに音程を揺らす。補充やベスト更新の音は毎回同じにして「ごほうびの合図」として覚えられるようにする。
- **失敗は責めない**：動かせないときは、低く柔らかい下降2音を短く鳴らすだけ。終了音も主音に落ち着いて終わる。
- 右上のボタンで音のオン・オフを切り替えられる（設定は保存）。

## ファイル構成

```
public/          公開するファイル一式（Cloudflare Pages の出力ディレクトリ）
  index.html
  style.css
  logic.js       ルール本体（描画から独立。Node からも読み込める）
  game.js        2D盤の描画とスワイプ操作
  sound.js       効果音（Web Audio で合成）
  favicon.svg
  _headers       Cloudflare Pages 用のレスポンスヘッダー
wrangler.toml    Cloudflare Pages の設定（出力ディレクトリ = public）
```

## ローカルで動かす

```sh
npx http-server public -p 8787
# → http://localhost:8787/
```

## Cloudflare Pages で公開する

### Git 連携（おすすめ）

1. Cloudflare ダッシュボード → Workers & Pages → Create → Pages → 「Connect to Git」でこのリポジトリを選ぶ。
2. ビルド設定:
   - Framework preset: `None`
   - Build command: （空欄）
   - Build output directory: `public`
3. 「Save and Deploy」。以降は `main` に push するたびに自動で公開されます。

### コマンドで直接アップロード

```sh
npx wrangler pages deploy public --project-name peg-block
```
