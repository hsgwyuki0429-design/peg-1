# ペグブロック

十字盤のペグソリティアに 2048 の合体ルールを組み合わせた、1人用の得点パズル。
上から見た盤で、数字の書かれた玉（ビー玉）をスワイプして遊びます。ビルド不要の静的サイトです。

見た目は blockmancala（同じ作者のゲーム）に合わせています。青い背景・くぼんだマス・色・丸ボタン・王冠のベストスコア・結果画面は、そこから流用しています。

## ルール

- 7×7 のうち 33 マスを使う英国式の十字盤。開始時は中央だけが空きで、残り 32 マスに「2」の玉が並ぶ。
- 玉をスワイプすると、その方向に隣り合う**同じ数字**の玉を飛び越えて、その先の空きマスへ着地する（タップで選んでから移動先をタップしても動かせる）。斜めには動けない。
- 飛び越えた玉は取られ、動かした玉は着地したマスで数字が 2 倍になる。できた数字がそのまま得点。
- 四方の 2×3（腕）のどれかで玉が 1 個もなくなったら、その腕の 6 マスに玉がまるごと補充される。中央の 3×3 は補充されない。
- **補充される数字は、そのとき盤上にあるいちばん小さい数字**。2 が 1 個もなければ 4、4 もなければ 8…と上がっていく。同時に複数の腕が空いたら、すべて同じ数字で補充される。補充は合体と得点の処理のあとに起きる。
- 玉の色は数字ごとに決まっている（2 赤、4 オレンジ、8 黄、16 緑、32 水色、64 青、128 紫、256 ピンク、512 白、1024 金、その先は巡回）。
- どの玉にも合法な手がなくなったら終了。得点・残りの玉・最大の数字・補充回数を表示し、ベストは得点で記録する。
- 「戻す」とヒントはない。

## 玉の動き

本物のビー玉で遊んでいるように見えるよう、簡単な物理で動かしています（`public/game.js`）。

- **跳ぶ**：重力の放物線で飛び（水平は等速）、着地すると反発係数ぶんだけ小さく何度か弾み、穴のくぼみの中で揺れてから止まる。高さは「少し大きく・少し上に・影が離れて薄くなる」で表す。
- **取られる・合体**：跳んだ玉が真上を越えたところで、取られる玉が指でつまみ上げるように持ち上がって消える。着地した瞬間に数字が 2 倍になり、玉がばねのようにふくらんで戻る。
- **補充・ゲーム開始**：玉が上から落ちてきて弾み、穴に収まる。
- **選ぶ・押す**：選んだ玉は少しつまみ上がる。スワイプの途中は指に押されてくぼみの中で寄り、動かせない向きなら少し転がってから戻る。
- **転がる**：玉の中のすじ模様が進んだ向きへ流れ、回っているように見える。
- **音**：着地の音は玉が当たった瞬間に、弾むたびに小さな「こつ」を鳴らす。

## 効果音の設計

気持ちよく聞こえるように、音響心理学の知見をもとに次のように作っています（`public/sound.js`）。

- **すぐ鳴らす**：音と動きのずれは数十msでも気づかれるため、操作と同時に鳴らす。
- **協和する音だけ**：倍音が整数倍に並ぶ音（サイン波＋弱い倍音）と、どの音を重ねても濁らないメジャー・ペンタトニック音階を使う。
- **耳に刺さる帯域を削る**：不快さに最も効く 2〜4kHz を避けるため、基音を低めにしてローパスをかける。うなりの原因になるデチューンもしない。
- **達成感を音程で**：大きい数字ができるほど、連続で合体するほど音が上がる。上がりすぎると耳障りなので上限を設け、2.5秒手が止まったらリセット。
- **聞き飽きさせない**：合体音は毎回わずかに音程を揺らす。補充やベスト更新の音は毎回同じにして「ごほうびの合図」として覚えられるようにする。
- **失敗は責めない**：動かせないときは、低く柔らかい下降2音を短く鳴らすだけ。終了音も主音に落ち着いて終わる。
- 右上のボタンで音のオン・オフを切り替えられる（設定は保存）。

## ファイル構成

```
public/          公開するファイル一式（Cloudflare Pages の出力ディレクトリ）
  index.html
  style.css
  logic.js       ルール本体（描画から独立。Node からも読み込める）
  game.js        盤の描画・スワイプ操作・玉の動き
  sound.js       効果音（Web Audio で合成）
  favicon.svg
  fonts/         Nunito と数字の「1」用フォント（SIL Open Font License、fonts/OFL.txt）
  _headers       Cloudflare Pages 用のレスポンスヘッダー
wrangler.toml    Cloudflare Pages の設定（出力ディレクトリ = public）
```

## ローカルで動かす

```sh
npx http-server public -p 8787
# → http://localhost:8787/
```

## Cloudflare Pages で公開する

### Git 連携（おすすめ）

1. Cloudflare ダッシュボード → Workers & Pages → Create → Pages → 「Connect to Git」でこのリポジトリを選ぶ。
2. ビルド設定:
   - Framework preset: `None`
   - Build command: （空欄）
   - Build output directory: `public`
3. 「Save and Deploy」。以降は `main` に push するたびに自動で公開されます。

### コマンドで直接アップロード

```sh
npx wrangler pages deploy public --project-name peg-block
```
